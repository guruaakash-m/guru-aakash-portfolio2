# Guru Aakash M — Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Set Framework Preset to **Other**.
4. Leave Build Command empty.
5. Set Output Directory to `.` (or leave the default if Vercel detects the static site).
6. Deploy.

## Before publishing
- Verify the email address and social profile URLs in `index.html`.
- Confirm the project descriptions and add links to real repositories or live demos.
- Add only technologies you can confidently discuss in an interview.
- Add a real resume PDF if you want a working resume download link.

No build tools or frameworks are required.
